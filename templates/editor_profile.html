Integrations

An API key lets a script or an AI tool read and edit your drafts as you. It works as a bearer token on the JSON API and on the MCP endpoint, and carries exactly the access your account has — no more.

{{if .Profile.APIToken}}

Treat it like a password. Anyone holding it can read and change every draft you can.

Add to Claude Code

claude mcp add --transport http intro-nyc \
  {{.BaseURL}}/mcp \
  --header "Authorization: Bearer {{.Profile.APIToken}}"

Add to a client that reads mcp.json

{
  "mcpServers": {
    "intro-nyc": {
      "type": "http",
      "url": "{{.BaseURL}}/mcp",
      "headers": {
        "Authorization": "Bearer {{.Profile.APIToken}}"
      }
    }
  }
}

Call the API directly

curl -H "Authorization: Bearer {{.Profile.APIToken}}" \
  {{.BaseURL}}/api/drafts

The MCP tools cover listing, creating, reading, editing, sharing and deleting drafts, and searching the Charter and Administrative Code. They are the same endpoints the editor itself uses.
